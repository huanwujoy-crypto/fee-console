Privacy Policy

This policy applies to Webull Gmail Sharesight Sync, a private application operated solely for its owner's personal investment records.

Google user data accessed

The application requests exactly https://www.googleapis.com/auth/gmail.readonly. This scope technically permits the application to view all email messages and Gmail settings in the authorized mailbox. The application deliberately limits its actual processing to searches for matching Webull trade execution notifications and transiently reads only the message content and authentication metadata needed to validate and extract trade date and time, market, side, symbol, quantity, price, and currency.

How data is used

Extracted trade facts are used only to detect duplicates, classify an event for controlled processing, reconcile the owner's Webull records with the owner's Sharesight portfolio, and create an audit trail. The application does not send email, alter messages, place trades, modify broker records, advertise, profile users, sell data, or use Google user data to create, train, or improve any artificial-intelligence or machine-learning model.

Storage and retention

OAuth client credentials and the refresh token are stored in Google Secret Manager with restricted service-account access and are retained until they are revoked, replaced, the application is disabled, or a valid deletion request is completed. Short-lived access tokens and complete message bodies are processed only in memory and are not retained as application state.

Minimum extracted transaction facts, message and economic fingerprints, validation outcomes, synchronization receipts, and reconciliation audit evidence may be retained for up to seven years for duplicate prevention and personal financial-record integrity, unless the owner requests earlier deletion. Cloud application logs exclude complete message bodies and credentials and are retained for 30 days. Data that is no longer required under these rules is deleted.

Sharing and transfer

The application does not sell Google user data. Minimum derived trade details may be transferred only to the owner's Sharesight account to perform the user-requested synchronization and reconciliation. Google Cloud processes data only as needed to authenticate the application, run the private workflow, protect secrets, deliver events, and retain the minimum state and audit evidence described above. No other transfer is permitted except where legally required.

Limited Use

Google user data is used only to provide and improve this owner-facing synchronization feature. It is not used for advertising, marketing, sale, creating, training, or improving any AI or machine-learning model, creditworthiness assessment, lending, or any unrelated profiling. A human will not read Gmail message content unless the account owner gives explicit consent for a specific message, or access is strictly necessary to investigate a security incident, prevent abuse, or comply with law. Any such access is limited to the minimum necessary purpose.

Security

Source access is read-only. The application uses least-privilege service accounts, encrypted secret storage, authenticated service endpoints, idempotency and duplicate checks, and fail-closed review gates for uncertain events.

User control

The owner may revoke the application's Google access at any time from Google Account third-party connections; revocation stops future Gmail access. To request deletion, email huanwu.joy@gmail.com from the authorized mailbox with the subject “Delete Webull Gmail Sharesight Sync Data” and state whether the request covers OAuth credentials only or all application data.

Access and deletion requests will be acknowledged and completed within 30 days. A completed full-deletion request disables and deletes the active OAuth credential and deletes the extracted state and audit data controlled by this application. If applicable law requires a specific record to remain, the owner will be told the exact legal basis, the data retained, and the fixed retention period. No general operational or “integrity” exception overrides a valid deletion request.

Google API Services User Data Policy

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements, and the Google Workspace API User Data and Developer Policy.
