Webull Gmail Sharesight Sync

This is a private, single-user investment-record workflow. It does not place trades, change broker records, or send or modify email.

Purpose

The application reads Webull trade execution notifications in the account owner's Gmail mailbox, extracts the minimum trade details needed for reconciliation, checks for duplicates, and prepares or records eligible transactions in the owner's Sharesight portfolio under controlled validation rules.

Google access

The application requests exactly https://www.googleapis.com/auth/gmail.readonly. This scope can technically view all email messages and Gmail settings in the authorized mailbox. The application deliberately uses that access only to search for and read matching Webull trade execution notifications. It cannot send, delete, archive, label, or modify messages.

Controls

Ambiguous, partial, unsupported, unusually large, or otherwise exceptional events are held for supervised review. Gmail and Webull remain read-only source systems.
