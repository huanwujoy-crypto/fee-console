# XUAN-IB 开市前行动版 v2

## 范围

现有 XUAN-IB 网址在有美股或欧股交易的工作日，13:00 HKT 生成一页式行动版，目标 13:20 HKT 前公网可见。只显示：

1. 本轮补仓（规划，非下单）；
2. 挂单提醒，买单和卖单分开；
3. 现金优先补仓参考；
4. 股票四类配置。

页面不设页签，不显示持仓总览、风险、ETF、家庭组合、事件、决策或长篇说明。这些内容将在第二阶段转入独立周日版。

## 数据来源

| 显示 | 必需数据 | 数据源 | 处理 |
|---|---|---|---|
| 挂单提醒 | 当前 LIMIT orders | IB orders + positions | 实时只读，用当前价格显示距限价及观察趋势 |
| 股票四类 | 当前持仓及业主分类 | Sharesight IB-HK Custom group `83569`（资产类别） | 按 Sharesight USD 市值汇总，显示数据日 |
| 现金池 | IB 现金、NOAH-HK 现金 | IB account summary + Sharesight NOAH-HK cash | Sharesight 只读，允许同步延迟，显示数据日 |
| 补仓指引 | 四类市值、现金池、待 CALL、当前买单 | 上述同轮数据 + 受控预留流水 | 先扣除现有买单名义金额，再计算可补仓现金 |

## 取数简化

- 正常生成只读 IB `accountSummary` / `orders` / `positions`。`positions` 只用于挂单币种、当前价格和趋势；不读 `trades`，不执行任何账户写入。
- 不再读取 9 个 Sharesight 组合；只读 IB-HK `资产类别` 及 NOAH-HK 现金必需数据。
- 官方只读 API 已验证返回 `custom_group.id=83569`、`name=资产类别`；2026-09-24 的 IB-HK 读取中未分类数为 0。类别为美国底仓、美国科技、非美发达、新兴市场、主题投资及防御资产。后两类不进入股票四类分母。
- 为避免美股开市后已成交、Sharesight 尚未同步造成双重口径，改为欧股最早开市前生成。美股收市后由既有 Gmail 流程先更新 Sharesight；本页要求 IB-HK 与 NOAH-HK 的 `sourceDate` 与选定的最近已完成交易日一致，不一致则不用旧值发布。
- 当前 BUY 挂单按“剩余数量 × 限价”预占现金，并按 Sharesight 业主分类显示“当前 → 挂单后 → 参考目标”。SELL 挂单不预计为可用现金。
- `xuan-ib-night-action-preview.mjs` 只生成本地排版预览；未接入的 IB 挂单、现金和补仓数据明确显示“未取得”，不会把空数组或旧金额冒充当前结果。
- 当前候选页一轮只读三个 IB 端点及两个 Sharesight 组合；不读成交，不调用写入端点。
- 专用捕获器会拒绝任何超出上述两个 IB 只读端点的调用。来源若保留亚分（sub-cent）FX 精度，只在规划视图按美元分取整；原始私有回执不修改。
- 若来源日、NOAH-HK、待 CALL 预留或买单分类不能确认，本轮不沿用旧的补仓金额。

## 本轮实施边界

新口径自 2026-09-28 起生效；旧报告的历史时间证据保持不变。整个流程只读，不下单、撤单、改单、转账或写入 Sharesight。
