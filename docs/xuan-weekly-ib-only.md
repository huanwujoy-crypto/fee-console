## 私密周报运行与验收

- `cloud/xuan-weekly/weekly_job.py` 固定读取 IB 查询、网关只读 portfolios/performance 与四只公开 ETF 行情；没有账户写入接口。
- 先核对实时组合名及 ID，再调用既有风险身份、分类、系数及精确计算引擎。不重新定义风险系数。
- 官方 IB 现金及证券转仓调整后，A/B/C 使用同一期初与同资金路径。行情最多容许三天末端缺口，显示实际共同完整数据日；中间缺价、币种不符、拆股及过期日历须失败，不伪造结果。
- 2026 年 LSE 日历到期后须审核扩展，不能无提示延用。IB 查询 365 天窗口未来失去期初前须接入已归档历史；当前缺少期初时明确失败。
- 每次输出均在私密 bucket 的唯一 `weekly/<UTC时间>-<UUID>/` 下，不公开原始资料、不回写行情或 Sharesight，不覆盖已保存报告。
- `bundle.json` 持续保存风险身份清单；取前一成功 bundle 作为下一轮依据，避免每周重置首见分类。
- HTML 只有风险和 ABC 两部分，无总览、持仓列表。数据日分开显示。Google 登录后的对象链接可访问，不能把重定向临时凭据链接作为固定入口。
- 专用 Cloud Run Job 为 `xuan-weekly-report`；单任务、零重试、600 秒上限。手动验收通过前不启用 Scheduler。
- 拟用 Cloud Scheduler：`0 10 * * 0`、`Asia/Hong_Kong`；专用触发身份仅允许运行此 Job，不能读源凭据。正式启用须遵守仓库日程审批边界。
