云同步（GitHub Gist）

连接后，每次改动自动推送到你 GitHub 账号下的一个私密 Gist，打开页面时自动拉取 —— 手机、电脑之间无需再导入导出。令牌只保存在本设备浏览器里，不会写进任何导出文件。

怎么获取令牌 (Personal Access Token)？
1. 登录 GitHub → 右上角头像 → Settings → 左栏最底部 Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)。
2. Note 随便填（如 fee-console），Expiration 选 No expiration，Scopes 只勾 gist 一项。
3. 点 Generate，把生成的 ghp_… 字符串复制过来粘到上面。这一步只需做一次；换新设备时把同一个令牌再粘一次即可自动找到同一份数据。

计算口径

管理费 = 日均 AUM × 年费率 × 当期实际天数 / 365。日均 AUM 采用 Modified Dietz 分母：期初总资产 + Σ(出入金 × 剩余天数/当期天数)。有每日净值时可用「日均 AUM 覆盖」替代。

当月净收益 = 期末总资产 − 期初总资产 − 净出入金。已实现 + 未实现 + 股息全部涵盖。

Carry = max(0, 累计净收益 − 高水位线) × Carry 比例。计提后水位线上移；亏损月 Carry 为 0 且水位线不动，须先补回亏损。

不含 clawback（回拨）：已收 Carry 在后续亏损时不退回，高水位线只保证不重复计提同一段收益。
