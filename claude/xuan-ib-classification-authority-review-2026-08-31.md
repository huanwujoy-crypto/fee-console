## 4. 七组合四桶映射：无标签不等于没有规则

`claude/xuan-ib-portfolio-registry.json` 的既有七个 `role=family` 组合仍是家庭四桶范围；AI-only 辅助组合和 excluded 组合不能因本次复核混入四桶。`claude/four-bucket-mapping.json` 中已批准的规则继续有效，不因某条持仓没有 Label 就擅自添加新规则或恢复“全部未分类”的说法。

分类依次检查：明确现金身份 → 逐仓 ID 与名称交叉核验 → 整组合规则 → 精确通用资产标签 → 未知。已验证适用的整组合规则可以覆盖无 Label 持仓；`Semi Liquid` 数量减去逐仓 overrides 数量不是未分类数量。现金身份无法核实时，不能只凭名称或普通证券类型猜测，也不能静默当成零。

“规则仍有效／某项可被规则覆盖”与“本期七组合完整持仓已经验收”是两种不同结论。后者仍需同一时点的全范围、分页／懒加载完整性、逐行去重、现金身份及金额对账证据。仅阅读 mapping 或有 `scope.complete` 声明，不能宣称全量审计完成；缺项仍按既有字段级降级和已批准日期快照处理。
